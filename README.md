## Overview

**Representational Effective Theory (RET)** describes the computation of a *frozen*
LLM in terms of learned **macrostates** rather than microscopic activations. A
lightweight encoder maps a mid-layer hidden-state prefix `h_{0:t}` into a
low-dimensional macrostate `z_t`, and a predictor forecasts `z_{t+1}` from `z_t`
under a BYOL/JEPA-style self-supervised objective with an EMA teacher:

```
L = || T_phi( f_theta(x_t) )  −  f_theta_bar(x_{t+1}) ||_1
```

RET asks for three properties of a good effective theory and tests each
empirically:

| Desideratum | What it means | Where it is tested |
|---|---|---|
| **Abstraction** | discard token-local detail, keep macro-structure | mental-state trajectories, temporal consistency, MMLU |
| **Approximate closure** | `z_{t+1}` predictable from `z_t` alone | held-out self-prediction R² |
| **Practical relevance** | useful for interpretation / prediction / control | mental state, sycophancy, steering |

The four headline results, and the command to reproduce each, are in
[Reproducing the paper](#reproducing-the-paper).

## Installation

```bash
# Python ≥3.9 (the pinned requirements.txt targets 3.11+, Torch ≥2.8)
conda create -n ret python=3.11 -y && conda activate ret   # or any venv

pip install -e ".[all]"          # core + dev + SAE baseline + analysis tools
python -m spacy download en_core_web_sm   # only for the MMLU t-SNE figure
```

`pip install -e ".[all]"` pulls `pytest`, `sae-lens` (SAE baselines),
`umap-learn`, and `anthropic`. Pinned versions are in `requirements.txt`.

Some pipelines call the **Anthropic API** (the MIS judges, the SYCON-Bench
judge, and the sycophancy dataset generation/filtering). Set:

```bash
export ANTHROPIC_API_KEY=...
```

A CUDA GPU is required for hidden-state extraction and RET training; the
paper's experiments ran on NVIDIA H100/H200.

## Repository structure

```
ret/                     Core library
  extraction/hooks.py    Frozen-LLM hidden-state extraction
  models/                Encoder (causal transformer), predictor, EMA teacher
  losses/                Prediction (L1), supervision head, VICReg (unused in paper cfg)
  training/trainer.py    End-to-end JEPA training loop
  data/, config.py       Dataset + nested-dataclass config (YAML + CLI overrides)
configs/<Model>/         Per-backbone configs: GptOss20B, Pythia160M,
                         Qwen2.5-14B-Instruct, Qwen3.5-35B-A3B (+ baselines, cache)
scripts/                 Entry points (one subfolder per experiment)
evaluation/              Evaluation libraries paired with scripts/
data/                    Shipped prompt sets, dataset splits, released sycophancy data
tests/                   pytest suite
```

Configuration merges in the order **defaults → YAML file → CLI `key=value`**, e.g.

```bash
python scripts/train.py configs/Pythia160M/ret_pile.yaml encoder.z_dim=128 training.batch_size=16
```

See `configs/CONFIG_REFERENCE.yaml` for every field.

## Data and artifacts

This repository ships **code, configs, prompt sets, dataset split metadata, and
the released multi-turn sycophancy dataset**. Large binary artifacts —
hidden-state caches, model checkpoints, figures, and full `outputs/` — are
*not* committed; they are regenerated by the pipelines below (and are
`.gitignore`d).

- `data/math_problems/` — curated reasoning prompts, including the paper
  Figure 6 prompt and the 33-prompt steering-robustness set.
- `data/sycophancy/augmented_{debate,false_presupposition}/` — the **released
  ~14k multi-turn sycophancy dataset** (FP + Debate), with the questions,
  presuppositions, corrections, pushbacks, and split indices.
- `data/{numina_math,tiny_stories,mmlu,...}/` — split metadata; hidden states
  are produced from the matching `configs/.../cache/*.yaml`.

Train a RET model (the method itself; Section 3, Appendix C):

```bash
python scripts/train.py configs/GptOss20B/ret_auth_jepa_l11.yaml
```

Backbones / layers used in the paper: GPT-OSS-20B (L11), Pythia-160M (L6),
Qwen2.5-14B-Instruct (L23), Qwen3.5-35B-A3B (L19); macrostate dim `d_z = 128`.

## Reproducing the paper

Each result corresponds to one subtree of `scripts/` + `evaluation/`. Commands
below use the GPT-OSS-20B / NuminaMath setting from the paper; swap the config
for other backbones.

### 1 · Approximate closure — Figure 2 (Section 2 / Appendix D)

Held-out self-prediction R² over a matched 2-layer-MLP capacity sweep. RET beats
raw `h`, PCA-128, and SAE on every backbone–dataset pair. Closure probes always
use MSE so R² is comparable across methods.

```bash
python scripts/closure/train.py \
    configs/GptOss20B/ret_auth_jepa_l11.yaml \
    configs/GptOss20B/baselines/h_l11.yaml \
    configs/GptOss20B/baselines/h_pca128_l11.yaml \
    configs/GptOss20B/baselines/sae_l11.yaml
```

### 2 · Mental state — Section 4

**Interpretable reasoning trajectories (Fig. 1, App. E).** Cluster macrostates
(K-means K=64 → 12 groups), name them with an LLM, render held-out trajectories:

```bash
python scripts/clustering/train_centers.py \
    --config configs/GptOss20B/ret_auth_jepa_l11.yaml \
    --variants z h h_pca --windows 1 --Ks 64 --seeds 1
python scripts/clustering/test_assign.py \
    outputs/GptOss20B/numina_math/ret_jepa_auth/clustering --all-combos
```

**Mental-state Interpretability Score (RET 5.61 ± 1.65 vs SAE 4.24; Fig. 9,
App. G).** Use the `both` subcommand — its defaults *are* the paper config;
`ret`/`sae` are dev-only and do not reproduce the headline number:

```bash
python scripts/mis/build_sae_latent_names.py \
    --llm-config configs/GptOss20B/baselines/sae_l11.yaml \
    --top-k 5 --output-dir outputs/.../baselines/sae_l11/interp_score
python scripts/mis/run_mis.py both \
    --clustering-dir outputs/.../clustering/w1/K64/seed1/analysis/weighted_tau0.1/grouped_alpha1.0 \
    --sae-latent-names outputs/.../baselines/sae_l11/interp_score/sae_latent_names.json \
    --num-samples 100
```

**Temporal consistency (Fig. 3)** and **MMLU semantic-vs-syntactic t-SNE
(App. I / Fig. 22):**

```bash
python scripts/probing/plotting/tsne_mmlu.py <pythia_checkpoint>.pt --group
```

### 3 · Early sycophancy prediction — Section 5

A token-level probe predicts eventual turn-level sycophancy from the first
5–10 % of a response; **RET (Supervised)** beats all hidden-state baselines
including a Transformer-Block probe. The ~14k-conversation dataset is released
under `data/sycophancy/` (regenerate with `scripts/sycophancy/generate_*` /
`filter_*` if desired).

```bash
# SYCON-Bench multi-turn generation + hidden-state extraction → judge → metrics
python scripts/sycophancy/run_benchmark.py --model Qwen/Qwen2.5-14B-Instruct --scenario debate --layers -1
python scripts/sycophancy/run_judge.py   --input data/sycophancy/debate/Qwen2.5-14B-Instruct/conversations.jsonl --scenario debate
python scripts/sycophancy/run_metrics.py --judge_results data/sycophancy/debate/Qwen2.5-14B-Instruct/judge_results.jsonl

# Probes (RET vs hidden-state baselines)
python scripts/probing/probe.py --experiment sycophancy --probe all \
    --sycophancy_data_dir data/sycophancy/debate/Qwen2.5-14B-Instruct \
    --sycophancy_layer 23 --sycophancy_mode debate
```

### 4 · Unsupervised steering — Section 6

Attractor / repulsor interventions on cluster centers (reusing the encoder and
clusters from result 2). E.g. the Figure 6 case study — steering toward C35
turns sequential summation into closed-form `n(n+1)/2`:

```bash
python scripts/unsupervised_steering/steer.py \
    --clustering-dir outputs/.../clustering \
    --problem-id paper_fig6_sum_1_to_11 \
    --target-cluster 35 --duration 50 --strength 0.5 --gradient-steps 3

# 33-prompt robustness number (30/33 vs SAE 20/33)
python scripts/unsupervised_steering/analyze_g7_behavioral.py <sweep_root>
```
